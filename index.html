1. はじめに 〜 本日のミッションと提案の心得 〜 ▲ 目次へ

丸紅I-DIGIO／丸紅システムズの皆さん、本日のワークショップへようこそ！前回のストレージ勉強会（満足度4.77）を踏まえ、今回は「現場で案件を発掘し、顧客に最適な提案を組み立てる実践力」を鍛えるプログラムです。

◆ 提案の基本姿勢：『お客様にとってのベストな選択肢を第一に考える』
製品ありきの売り込みではなく、顧客の既存資産・運用課題・将来計画に真摯に寄り添い、客観的かつ論理的な比較提案を行います。徹底的に比較検討した結果、仮に「今回はNetAppを継続・増設することがお客様にとって最善」という結論に至った場合も正解です。顧客の利益を最優先にする誠実なコンサルティング姿勢こそが、長期的な信頼関係の基盤となります。
◆ AI（SalesChat / 生成AI）も活用して素早く調べよう！
知識を暗記している必要はありません。ワークショップ中や調べものの最中、競合機能の用語や技術仕様に迷ったら、社内ポータルに加えてAIアシスタントをフル活用してリサーチし、提案の引き出しを増やしましょう。

4. 登場する頼れる仲間たち 〜 Dell製品ポートフォリオ図鑑 〜 ▲ 目次へ

どのような製品を選び、どう組み合わせるかは【各チームの自由】です！顧客にとってベストなアーキテクチャを自由に組み立ててください。

カテゴリ / 製品名 製品の特徴・強み 提案での主な役割・組み合わせ例
【サーバー】
PowerEdge		業界シェアNo.1の高集約・高信頼サーバー。iDRACによる高度な運用自動化。3Tier構成の仮想化コンピュート基盤として外付けストレージと連携。
【プライマリストレージ】
PowerStore		NVMeネイティブ、常時4:1データ削減保証、Anytime Upgrade（無停止刷新）。仮想化基盤の本命。NetApp AFF/FASからの移行で性能・運用・TCOを大幅改善。
【プライマリストレージ】
PowerVault ME5		圧倒的低価格・シンプルな専用SAN/DASストレージ。簡単セットアップ。コスト最優先、バックアップ専用ターゲット、エントリー仮想基盤の最適解。
【プライマリストレージ】
Unity XT		実績多数のエンタープライズ・ユニファイド（SAN/NAS）。堅牢性とコストの両立。中規模環境でファイル共有と仮想基盤を柔軟に統合する受け皿。
【重複排除ストレージ】
Data Domain (PowerProtect DD)		業界標準の超高効率重複排除（平均65:1）。堅牢なデータ保護・イミュータブル保管。仮想環境のバックアップ先として統合し、保存容量とネットワーク負荷を激減。
【データ保護ソフト】
PowerProtect Data Manager (PPDM)		次世代VMware保護（Transparent SnapshotsによるVM無停止保護）。K8s対応。仮想マシンに一切負荷をかけずに高速・安全なバックアップ運用を実現。
【SaaSバックアップ】
PowerProtect Backup Services (PPBS)		クラウドネイティブ（SaaS）バックアップ。インフラ構築不要で即時利用可能。M365、エンドポイント、クラウド上のワークロードを一元バックアップ。
【統合管理】
DDPC / DPC		Data Domain Management Center (DDPC) ＆ Data Protection Central (DPC)。複数拠点のData Domainやバックアップ環境の一元監視・容量可視化。
【HCIアプライアンス】
AX / XC シリーズ		AX: Microsoft Azure Stack HCI専用ノード
XC: Nutanix搭載アプライアンス		3TierからHCIへの刷新提案。運用シンプル化やハイブリッドクラウド連携。

6. ロールプレイ対決 〜 仮想環境移行クエスト 〜 ▲ 目次へ
■ 顧客カルテ（商談シナリオ）
【顧客プロファイル】 中堅製造業（情報システム部 インフラ担当課長 ＆ 主任）
【現行システム】 物理サーバー数台 ＋ NetAppストレージ（3Tier構成、NFS接続）／ VMware vSphere（VM約60台、Win/SUSE Linux混在）
【顧客のリアルな悩み・発言】
1. 「NetAppの保守が来年切れるが、担当者が異動して各VMの詳細（容量・負荷・OS）を把握できていない」
2. 「ずっとNFSで使ってきたので、SANに変えると設計やデータ移行が大変そうで不安」
3. 「WindowsとSUSE Linuxが混ざっているが、Dellに替えて容量やバックアップはどうなるのか？」
4. 「3Tierを続けるべきか、HCIにするべきかも悩んでいる。NetApp継続の選択肢も含めてフラットに提案してほしい」
■ 審査ルーブリック（100点満点）
評価項目 配点 合格基準（顧客ファーストの提案ができているか）
顧客ファーストの傾聴＆Live Optics誘導25点「詳細不明」に対し、無理に売り込まず無償Live Optics診断を誠実に提案できたか。
客観的な〇×比較表の活用25点自作〇×表を提示し、NetAppの良さも認めつつ顧客メリットを論理的に説明できたか。
製品構成の妥当性 (PowerSizer/DSC活用)25点PowerStore/PowerEdge/Data Domain/HCI等を自由に組み合わせ、最適な理由を語れたか。
営業・SEの連携＆クロージング25点営業とSEの息が合い、顧客の不安を払拭して「Live Optics診断実施」の合意を得られたか。
7. 実践力腕試し！ Microsoft Forms 小テスト 〜 ツール・AI検索OK 〜 ▲ 目次へ

出題カテゴリ 確認するスキル・論点 出題イメージ（例）

(羅針盤/ナレッジ/サポート)		適切なポータルから正確な公式情報を素早く見つけられるか「NetAppからPowerStoreへのデータ移行手順書（WhitePaper）のタイトルを検索して答えよ」

実践サイジング力		パラメータ入力から最適モデル・容量削減率を算出できるか「VM50台・総容量30TB・Win/Linux混在時、PowerStoreで4:1削減適用時の必要物理容量は？」
